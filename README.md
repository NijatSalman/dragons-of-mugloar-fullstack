# Dragons of Mugloar

A full-stack solution to the [Dragons of Mugloar](https://dragonsofmugloar.com/) game: a Spring Boot backend that
wraps the game API and plays the game autonomously, and a React web app that lets a player pick ads, buy items and
watch the dragon play.

## Status

Work in progress. Run instructions, architecture notes and results will be added as the project grows.

## Requirements

- Java 21
- Node.js 22 (frontend)
- Docker (optional, for the full stack with Prometheus and Grafana)

## Quick start

```bash
./gradlew test
./gradlew bootRun
```
